# 霓虹十一城 · NEON CITY 11

一款原创 3D 街机漂移竞速游戏。赛道以《QQ 飞车》经典“十一城”的海滨都市、跨海大桥、蓝光隧道、连续 U 型弯和两圈赛制为灵感，使用 Three.js 全程序化搭建，不包含腾讯的游戏模型、贴图、音乐或 Logo。

## 玩法

- 6 名车手、2 圈竞速，包含 5 名带轻度追赶机制的 AI 对手。
- 方向键或 `WASD` 驾驶；`Shift` + 方向漂移；松开 `Shift` 完成出弯并集气。
- 漂移分为 `DRIFT / GOOD / GREAT / PERFECT`，集满 25% 即可按 `Ctrl` 释放氮气。
- 接力加速带、护墙碰撞、车辆复位、三种追尾/车头/远景镜头。
- 手柄与移动端触控支持，桌面端和横屏移动端均有自适应 HUD。

## 键位

| 操作 | 键位 |
| --- | --- |
| 油门 / 刹车倒车 | `↑` / `↓` 或 `W` / `S` |
| 转向 | `←` / `→` 或 `A` / `D` |
| 漂移 / 松开放气 | `Shift` |
| 氮气加速 | `Ctrl` |
| 复位到赛道 | `R` |
| 切换镜头 | `C` |
| 暂停 / 继续 | `Esc` 或 `P` |
| 静音 / 全屏 | `M` / `F` |

手柄：`RT` 油门、`LT` 刹车、`RB` 漂移、`A` 氮气。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 技术说明

- Vite 7 + Three.js r180，ES modules，无后端。
- Catmull-Rom 闭环赛道采样、倾斜路面、程序化城市/海水/天空、InstancedMesh 护栏与车道线。
- 自定义漂移侧滑、集气、出弯小喷、氮气、碰撞和轻微橡皮筋 AI。
- WebAudio 实时合成引擎、轮胎、风噪、氮气、倒计时与音乐。
- 所有车辆、赛道和环境素材均由代码生成。
